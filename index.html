Web Application

E-Voting BEM UNWIRA

Overview

Aplikasi e-voting berbasis web untuk mendukung proses pemilihan Ketua Badan Eksekutif Mahasiswa secara digital. Sistem ini memungkinkan mahasiswa untuk melakukan pemilihan secara online dengan aman dan transparan.

Problem

Proses pemilihan BEM sebelumnya dilakukan secara manual, yang rentan terhadap kecurangan, membutuhkan waktu lama, dan kurang efisien dalam pengumpulan serta penghitungan suara.

Solution

Dikembangkan aplikasi e-voting berbasis web yang memungkinkan mahasiswa memilih secara digital dengan sistem autentikasi, enkripsi suara, dan dashboard pengelolaan kandidat serta hasil pemilihan.

Features

  • Authentication & Authorization
  • Candidate Management
  • Online Voting System
  • Face ID Verification
  • Real-time Voting Results
  • User Management
  • Admin Dashboard

Technology

Laravel PHP MySQL Bootstrap JavaScript

My Role

Full-stack developer — merancang database, mengembangkan backend dan frontend, serta mengimplementasikan fitur autentikasi dan sistem voting.

Result

Aplikasi berhasil digunakan untuk mendukung pemilihan BEM secara digital, meningkatkan efisiensi proses pemilihan dan transparansi hasil.

Overview

Problem

Dikembangkan platform digital yang mendokumentasikan sejarah, tradisi, budaya, dan kearifan lokal masyarakat Lamalera dalam format digital yang mudah diakses dan dilestarikan.

Features

  • Cultural Information Display
  • Historical Documentation
  • Tradition Archives
  • Local Wisdom Content
  • Multimedia Documentation
  • Responsive Design

Technology

Laravel PHP MySQL JavaScript Bootstrap

My Role

Full-stack developer — merancang arsitektur database, mengembangkan backend dan frontend, serta mengimplementasikan fitur dokumentasi multimedia.

Result
